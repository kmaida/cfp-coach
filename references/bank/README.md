# CFP evidence bank

This shared bank contains public evidence only: schedules, public session abstracts, popularity captures, and sourced trend observations. Read the active speaker's private records separately. A public speaker listing never supplies the active speaker's identity, preferences, or credentials.

Use `schedules/<conference>-<year>-schedule.md`, `popularity/<conference>-<year>-youtube.md`, `trends/YYYY-MM-trends.md`, and `accepted/<conference>-<year>.md` for public records. Create directories as needed. Each capture records source URL, retrieval date, edition, scope, and uncertainty. Distinguish public session type from confirmed acceptance route. Preserve source text and indicate truncation.

Store private submissions, organizer interactions, and speaker-specific interpretations inside the active profile directory. Keep an explicit link from each interpretation to the public evidence file and capture date. Do not place private interpretations in a shared schedule or export them as public evidence.

Submission entry fields: speaker, canonical talk identity/title, conference and edition, submitted date (unknown if absent), status, acceptance route (organic CFP / sponsored / curated / unknown), full verbatim abstract, source/provenance, captured date, updated date, feedback, and separate interpretation. Record rejections and waitlists as well as acceptances. Preserve paragraph breaks, dates, uncertainty, rejected title variants, and status history. Do not overwrite an earlier fact silently; add a dated update with its source.

Popularity tables record title, speaker, views, capture date, publication date when known, keynote status, and playlist/channel URL. Keep successive captures. Views measure audience attention, not committee selection; account for age, title, and speaker effects when possible.

Trend snapshots record domain, date, trajectory hypothesis, evidence, and limitations. Keep previous snapshots; a single capture cannot establish a trajectory. Personal angle tests belong in the speaker profile.

The bundled AI research is optional historical evidence. Select it only for relevant audiences; it is neither a current scan nor a default domain for a new speaker.
